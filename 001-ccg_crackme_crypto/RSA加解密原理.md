## 1. 最大公约数与互质：gcd(x, y) = 1

`gcd(x, y)`（Greatest Common Divisor，最大公约数）指能同时整除 x 和 y 的最大正整数。

当 `gcd(x, y) = 1` 时，称 x 和 y **互质**（coprime）——意z思是它们除了 1 之外没有其他公共因子。

例子：`gcd(8, 15) = 1`（8的因子是1,2,4,8；15的因子是1,3,5,15，没有公共的），所以8和15互质。而 `gcd(8, 12) = 4`，不互质。

**为什么RSA要关心这个**：RSA的公钥指数 `e` 必须和 `φ(N)`（下面讲）互质，否则后面求"模逆元"这一步会无解。

---

## 2. 欧拉函数 φ(n)

**定义**：`φ(n)` 表示"从1到n之间，有多少个数和n互质"。

比如 `φ(10)`：1~10中和10互质的数有 1,3,7,9 共4个，所以 `φ(10)=4`。

**RSA只需要一个特殊情况**：当 `n = p × q`（p、q是两个**不同的质数**）时，有一个非常简洁的公式：

```
φ(n) = (p-1) × (q-1)
```

这个公式是数论里证明过的定理，不需要你真的一个个数互质数——**但前提是你得知道 p 和 q 具体是多少**。这也是为什么RSA的安全性依赖于"大数分解困难"：如果只公开了 `n`，但不知道怎么拆成 `p × q`，就没法算出 `φ(n)`，也就没法往下推出私钥。

---

## 3. 欧拉定理

**内容**：如果 `gcd(a, n) = 1`，那么：

```
a^φ(n) ≡ 1 (mod n)
```

也就是把 `a` 自乘 `φ(n)` 次再对 `n` 取余，结果一定是1。

**这是RSA能"加密后又能解密回来"的数学根基**。后面推导私钥指数 `d` 就是直接建立在这条定理之上的。

---

## 4. 模逆元（modular inverse）

**定义**：给定 `a` 和 `n`，如果存在一个数 `x`，满足：

```
a × x ≡ 1 (mod n)
```

就说 `x` 是 `a` 关于模 `n` 的**模逆元**，记作 `a⁻¹ mod n`。

**存在条件**：`a` 和 `n` 必须互质（`gcd(a,n)=1`），否则模逆元不存在。这也解释了为什么第1节说 `e` 必须和 `φ(N)` 互质——因为我们要求的私钥 `d` 正是 `e` 关于 `φ(N)` 的模逆元：

```
d = e⁻¹ mod φ(N)     即   e × d ≡ 1 (mod φ(N))
```

**怎么算**：数学上用**扩展欧几里得算法（Extended Euclidean Algorithm）**求，Python直接一行 `pow(e, -1, phi)` 就能算出来（Python 3.8+ 内置支持负数次幂求模逆元）。

---

## 5. 模数的比特长度

`N` 的**比特长度**就是把 `N` 写成二进制后有多少位，直接决定了RSA的"理论安全强度"：

| N的比特长度 | 安全性 | 说明 |
|---|---|---|
| < 512位 | 完全不安全 | 现代电脑几秒~几小时内可分解 |
| 512~768位 | 已被攻破过 | 学术界早有分解记录 |
| 1024位 | 已不推荐 | 理论上大机构可分解 |
| **2048位** | **当前主流安全标准** | 银行、HTTPS等广泛使用 |
| 3072/4096位 | 更高安全余量 | 长期保密数据 |

**核心原因**：分解 `N=p×q` 的难度随位数**指数级**增长。位数越少，分解越容易——这正是你之前那道 crackme 的漏洞所在（`N` 只有64位，秒级可破）。

粗略换算：位数每增加约10位，暴力分解难度大约翻10倍以上（实际增长速度比这更快，因为最优分解算法的复杂度是亚指数级的）。

## 6. 完整的加密/解密过程

### 密钥生成
1. 随机选两个**大质数** `p`、`q`
2. 计算 `N = p × q`（公开的模数）
3. 计算 `φ(N) = (p-1)(q-1)`（**保密**，只有生成密钥的人算过一次，随后销毁）
4. 选一个 `e`，满足 `1 < e < φ(N)` 且 `gcd(e, φ(N)) = 1`（常见固定选 `e = 65537`，因为它是质数、二进制里1的个数少，加密运算快，且经验证安全）
5. 计算 `d = e⁻¹ mod φ(N)`（私钥指数）

最终：
```
公钥 = (e, N)   → 公开给所有人
私钥 = (d, N)   → 只有密钥拥有者知道，p、q、φ(N)全部销毁/保密
```

### 加密
把明文 `m`（必须是小于 `N` 的整数）加密成密文 `c`：
```
c = m^e mod N
```

### 解密
```
m = c^d mod N
```

**能解密回来的数学原理**：因为 `e × d ≡ 1 (mod φ(N))`，可以写成 `e×d = k×φ(N) + 1`（k是某个整数），所以：
```
c^d = (m^e)^d = m^(ed) = m^(k·φ(N)+1) = (m^φ(N))^k × m
```
根据欧拉定理 `m^φ(N) ≡ 1 (mod N)`，所以上式 `≡ 1^k × m = m (mod N)`。这就是整个RSA能"加密再解密拿回原文"的数学闭环。

### 签名/验证（和加解密反过来用）
- **签名**：`sig = m^d mod N`（用私钥"加密"）
- **验证**：`m' = sig^e mod N`，检查 `m' == m`（用公钥"解密"）

你之前那道crackme用的正是这个反过来的用法：程序里只留了公钥 `(e, N)`，正常情况下没法伪造签名；但因为 `N` 太小能被分解，我们才能"偷"出私钥 `d`，反过来伪造签名。
